# Local Beta Without Server

Если сервера пока нет, можно сделать первую закрытую бету прямо с твоего компьютера.

## Что это даст

- приложение на телефоне сможет ходить в backend на твоем ПК
- можно тестировать регистрацию, логин, квесты, магазин, инвентарь и прогресс
- подходит для твоих собственных устройств и нескольких людей в одной сети

## Ограничения

- это не настоящий публичный релиз
- телефон и компьютер должны быть в одной Wi-Fi сети
- если компьютер выключен, backend недоступен
- для тестеров из другого города этот вариант не подойдет

## Самый простой запуск

Из корня проекта запусти:

```powershell
.\scripts\Start-Local-Beta.ps1
```

Скрипт:

- поднимет Docker Compose
- определит локальный IP компьютера
- дождется ответа backend
- покажет готовый `API base URL`

## После запуска

Используй выданный адрес в мобильном приложении:

- на экране логина можно вручную ввести адрес API
- если собираешь APK, используй этот URL как `EXPO_PUBLIC_API_BASE_URL`

Пример:

```text
http://192.168.0.148:8000/api/v1
```

## Если что-то не работает

Проверь:

- телефон и компьютер в одной сети
- Docker Desktop запущен
- порт `8000` не заблокирован файрволом

Логи backend:

```powershell
docker compose logs api
```
