# Видение продукта

## Идея

`New Erra` — это мобильный квестер, который помогает человеку достигать реальной цели через ежедневные полезные действия.

## MVP

В первой версии приложение работает только с одной целью:

- **снижение веса**

## Принципы

- всё на русском языке
- никакого случайного мусора в квестах
- каждое задание должно помогать реальному похудению
- рост сложности идёт постепенно и предсказуемо
- UI должен быть современным, чистым и спокойным

## Базовые ежедневные квесты

- выпить норму воды
- пройти норму шагов
- удержаться в лимите калорий

## Основные экраны

- регистрация и анамнез
- главная
- квесты
- прогресс
- профиль
- настройки
