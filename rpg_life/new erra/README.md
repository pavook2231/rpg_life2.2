# New Erra

Новый продуктовый старт для мобильного приложения-квестера.

## Что внутри

- `apps/api` — backend на Node.js + Fastify + Prisma
- `apps/mobile` — мобильное приложение на React Native / Expo для iPhone и Android
- `packages/shared` — общая логика, типы и детерминированные квесты для снижения веса

## Что уже готово

- регистрация на русском языке с полным анамнезом
- вход, выход, смена пароля и подготовка восстановления доступа
- главная страница с прогрессом, серией дней и объяснением продукта
- ежедневные квесты по воде, шагам и калориям
- экран прогресса и статистики
- профиль и настройки с темой и языком
- backend API с JWT, Prisma и хранением ежедневных квестов
- live-режим по `EXPO_PUBLIC_API_BASE_URL` и fallback в demo-режим

## Текущая цель MVP

Первая и единственная цель первой версии: **снижение веса**.

## Как устроен сценарий

1. пользователь проходит регистрацию и анамнез
2. система создаёт первый день программы
3. каждый день пользователь получает полезные квесты
4. за выполнение начисляются XP и растёт серия дней
5. после закрытия дня открывается следующий день программы

## Быстрый запуск

Подробные команды лежат в [docs/runbook.md](./docs/runbook.md).

Коротко:

1. установить зависимости в `new erra`
2. запустить PostgreSQL
3. поднять `apps/api`
4. указать `EXPO_PUBLIC_API_BASE_URL` для live-режима или оставить demo-режим
5. запустить `apps/mobile` через Expo
